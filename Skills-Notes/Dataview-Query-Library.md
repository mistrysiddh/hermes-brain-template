# Dataview Query Library

Copy-paste Dataview blocks for this vault. Drop any of these into a note
(inside a ` ```dataview ` or ` ```dataviewjs ` fence) and adjust the folder
path if needed. Requires the **Dataview** plugin (already enabled).

## Sessions this week

```dataview
TABLE file.folder AS "Date folder"
FROM "Daily"
WHERE file.name != "README" AND file.name != "manifest" AND file.name != "Timeline"
WHERE file.mtime >= date(today) - dur(7 days)
SORT file.mtime DESC
```

## Stale promotion candidates (60+ days undecided)

Requires `Memory-Review/Promotion-Candidates.md` to exist (generated by
`Scripts/consolidate_memory.py`). This searches its own checkbox lines for
the `stale Nd` flag the script adds automatically.

```dataviewjs
const file = dv.page("Memory-Review/Promotion-Candidates");
if (!file) {
  dv.paragraph("No Promotion-Candidates.md found yet — run consolidate_memory.py first.");
} else {
  const content = await dv.io.load(file.file.path);
  const staleLines = content.split("\n").filter(l => /stale \d+d/.test(l));
  if (staleLines.length === 0) {
    dv.paragraph("No stale candidates right now.");
  } else {
    dv.list(staleLines.map(l => l.replace(/^- \[ \] /, "")));
  }
}
```

## Skill notes index (if you document skill usage per note)

```dataview
TABLE WITHOUT ID file.link AS "Skill Note"
FROM "Skills-Notes"
WHERE file.name != "README" AND file.name != "Dataview-Query-Library"
SORT file.name ASC
```

## Recently modified notes (any folder)

```dataview
TABLE file.folder AS "Folder", file.mtime AS "Modified"
FROM ""
WHERE file.name != "Dataview-Query-Library"
SORT file.mtime DESC
LIMIT 15
```

## Active projects

```dataview
TABLE status, created
FROM "Projects"
WHERE type = "project"
SORT created DESC
```

## Open next-actions across all projects

Pulls every unchecked task under a "Next actions" heading in `Projects/`.

```dataview
TASK
FROM "Projects"
WHERE !completed
```

## Notes with no outgoing links (possible orphans)

```dataview
LIST
FROM ""
WHERE length(file.outlinks) = 0 AND file.name != "Dataview-Query-Library"
```

## Files by tag

```dataview
TABLE file.tags AS Tags
FROM ""
WHERE contains(file.tags, "#project") OR contains(file.tags, "#research")
SORT file.name ASC
```
