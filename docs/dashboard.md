# Dashboard

The Hermes Brain template includes a **Dashboard** note designed to give you an at-a-glance view of your knowledge system, projects, and metrics.

## Dashboard Note

Located at: `03-📚 03-Resources/Templates/Dashboard.md`

This template note provides:

- **Quick stats** — Note counts, recent activity, project status
- **Project overview** — Active, on hold, completed projects
- **Area health** — Overview of your Areas of Responsibility
- **Recent notes** — Latest created/modified notes
- **Metrics** — Word count, tag distribution, link stats
- **Action items** — Outstanding tasks and reminders

## How to Use

1. Create a new note from the **Dashboard** template
2. Place it in your `00-📥 Inbox` or `01-🎯 01-Areas` as desired
3. Fill in the sections as your vault evolves
4. Update regularly (weekly or monthly) to keep it current

## Customization

Feel free to modify the dashboard to suit your workflow:
- Add or remove sections
- Change the metrics displayed
- Integrate with Dataview queries for live data
- Adjust the styling to match your preferences

## Example Dashboard Structure

```markdown

```
