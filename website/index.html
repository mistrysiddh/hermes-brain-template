Release Highlights · v1.24.0

What's New in the Template

🧭v1.24

Decisions, Principles & Axioms

Log hard-to-reverse choices from Decisions/TEMPLATE.md. The Alternatives Rejected section is mandatory, so agents stop re-proposing ideas you already ruled out. Axioms.md ships empty on purpose: it should hold your beliefs, not generic filler.

🛟v1.24

Local Git Safety Net

Hook session_git_snapshot.py into Hermes' on_session_end and every session gets its own commit you can git diff or revert. Local history only: it never pushes or fetches. A secret-scanning gate blocks the commit if anything looks like an API key or private key, and logs only the file path, never the content.

🗂️v1.23.1

Cron Runs Kept Separate

Cron logs, lock files and cron-run session notes now live in 04-Archives/Cron/, so Daily/ holds only your real chats. Upgrading? migrate_cron_sessions.py moves old cron notes over and is safe to re-run.

✅v1.23

Post-Install Verification

The installers now finish by running verify_install, which sanity-checks vault structure, plugins, the MCP server and the memory pipeline, so problems show up on day one instead of week three.

🎚️v1.23

Opt-In Feature Packs

Scripts are grouped into beginner, analyst, poweruser and experimental packs under _System/Scripts/features/. Start with the core and copy in more when you're ready.

🔍v1.23

Template Drift Checker

template_drift.py compares your vault to the latest template release by SHA-256 and sorts every file into safe, customized, outdated or missing, so you know exactly what an update will touch.

🗳️v1.22

Interactive Memory Review

promote_memory.py --review walks you through pending candidates one by one: promote to MEMORY.md or your User Profile, dismiss, or skip. Every action lands in the consolidation audit log.

🌙v1.22

Dream Cycle v2

dream_cycle.py was rebuilt as an autonomous reflection engine that consolidates memories between sessions, and now ships with its own test suite.

Full history in the release notes on GitHub.

Quick Start

5 Flexible Ways to Get Started

Choose the setup option that fits your workflow — from a 1-paste chat prompt to an interactive terminal script.

Fastest: Run the automated installer directly in your terminal

Downloads the latest template, asks where you want your vault, checks for Obsidian, registers HERMES_VAULT_PATH, then runs verify_install to confirm the vault structure, plugins, MCP server and memory pipeline are all wired up.

Windows (PowerShell): 
irm https://raw.githubusercontent.com/mistrysiddh/hermes-brain-template/main/_System/Scripts/Installers/install.ps1 | iex
Linux / macOS / WSL (Bash): 
curl -fsSL https://raw.githubusercontent.com/mistrysiddh/hermes-brain-template/main/_System/Scripts/Installers/install.sh | bash

Zero Manual Terminal Work: Paste directly into your Hermes / OpenClaw chat

Hermes will clone the repo, run the installer, configure the environment, and wire up the hourly archiving cron job automatically. 

Clone https://github.com/mistrysiddh/hermes-brain-template into a new "Hermes Brain" vault for me. Steps:
1. Ask me where I want the vault folder to live (default: ~/Hermes Brain on Linux/macOS, or %USERPROFILE%\Hermes Brain on Windows).
2. Clone the repo into that location.
3. Run the platform-appropriate installer (_System/Scripts/Installers/install.sh or install.ps1).
4. Relay any questions to me and confirm env.HERMES_VAULT_PATH is set.
5. Create an hourly session-archiving cron job named "hermes-brain-archive-hourly" pointing to <vault>/_System/Scripts/hourly_archive.py.
6. Show me the verify_install results and fix anything it flags.

Own Your Private Git Repo with Full Version History

Use GitHub's green "Use this template" button to fork the repository privately into your GitHub account, then clone it locally: 

git clone https://github.com/mistrysiddh/hermes-brain-template.git "Hermes Brain"
cd "Hermes Brain"
# Windows:
powershell -ExecutionPolicy Bypass -File .\_System\Scripts\Installers\install.ps1
# Linux/macOS:
chmod +x _System/Scripts/Installers/install.sh && ./_System/Scripts/Installers/install.sh

Zero Commitment: Test in a disposable sandbox

Creates a temporary copy in %TEMP% or /tmp without touching your real Hermes config or permanent directories: 

# Linux / macOS:
./_System/Scripts/Installers/try.sh

# Windows (PowerShell):
powershell -ExecutionPolicy Bypass -File .\_System\Scripts\Installers\try.ps1
