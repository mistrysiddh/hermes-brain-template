# 📊 Audit Reports & Telemetry

Automated telemetry, performance summaries, and integrity reports generated by the vault's background engines.

## 📑 Generated Reports

- **`Vault-Audit-Report.md`:** Produced by `_System/Scripts/vault_audit.py` (weekly/monthly). Checks for broken wikilinks, orphaned notes, stale memory reviews, and manifest integrity.
- **`Agent-Performance.md`:** Produced by `_System/Scripts/agent_performance.py` (weekly). Summarizes model usage, skill execution frequency, and session tokens.
- **`Token-Usage.log`:** Maintained by `_System/Scripts/hourly_archive.py`. Records token consumption per session and daily totals.
- **`Tag-Trends.log`:** Maintained by `_System/Scripts/session_tagger.py`. Tracks topic and skill tag frequency over rolling windows.
