Why Hermes Brain?

Built for developers who want control, transparency, and zero lock-in.

Human Review Before Memory

Nothing auto-promotes to agent memory. Every fact is staged in 04-Archives/Memory-Review/ for your approval first.

Readable Without Special Tools

Plain markdown files. Open in Obsidian, grep, VS Code, or Notepad. No proprietary format, no export step.

Portable & No Vendor Lock-in

Your files, your git repo, your backup strategy. Move between machines, OSes, or agents anytime.

Built-in Analytics Dashboard

Token usage, vault health, agent performance, skill analytics — all live in Dashboard.md with Dataview.

Zero-Setup for Hermes

One-paste install prompt wires the vault + hourly archiving. No separate integration work needed.

Personality Judgment Framework

12-dimension analysis template + auto-populating dashboard for communication pattern analysis.

Quick Start

Three ways to get running — pick your comfort level.

If you already run a Hermes agent, skip cloning entirely. Open INSTALL_PROMPT.md and paste one block straight into your Hermes chat:

Prompt 1

Installs the vault only

Prompt 2

Sets up hourly archiving cron (vault must exist)

Recommended

Prompt 3 (Master)

Does both in one paste: install vault + hourly cron, no follow-up needed

Clone and run the interactive installer:

# Linux / macOS
git clone https://github.com/mistrysiddh/hermes-brain-template.git
cd hermes-brain-template
chmod +x _System/Scripts/Installers/install.sh
./_System/Scripts/Installers/install.sh

# Windows (PowerShell)
git clone https://github.com/mistrysiddh/hermes-brain-template.git
cd hermes-brain-template
powershell -ExecutionPolicy Bypass -File .\_System\Scripts\Installers\install.ps1

The installer asks where to put the vault, which local embedding backend you want (Ollama or sentence-transformers), and whether to auto-register the vault path with the Hermes CLI.

Full manual control — follow SETUP.md step by step instead of using either installer. Best if you want to understand every piece before it's in place.
